CakeBar

generador de codigos de barra hecho en electron
escribes el valor y te sale pegado en el producto asi plano como etiqueta real
puedes exportarlo en png svg y pdf o imprimirlo directo con el boton de la impresora

como correrlo
npm install
npm run dev

como compilarlo
npm run build
para linux sale el AppImage y para windows el exe portable

eso es todo
